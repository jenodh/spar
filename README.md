# SPÅR

A digital experience exploring sustainable fashion, innovative materials and personal design.

## About the project

SPÅR is a collaborative web development project focused on creating a website based on an existing Figma design.

The project explores how design, technology and user experience can come together to communicate a concept through a responsive and accessible website.

## Project resources

### Design

Figma design file – shared privately with project collaborators.

### Project management

GitHub Project Board

## Technologies

The website is built using:

- HTML
- CSS
- JavaScript

## Project structure

The project is divided into the following phases:

1. Research & technical exploration
2. Project setup
3. HTML structure
4. Basic CSS
5. Mobile first layout
6. Desktop & responsive design
7. JavaScript functionality
8. Accessibility & quality assurance

## Development

The project is developed collaboratively using Git and GitHub.

### Getting started

1. Clone the repository:

   ```bash
   git clone ADD-REPOSITORY-URL
   ```

2. Navigate to the project folder:

   ```bash
   cd spar
   ```

3. Open the project in your code editor.

4. Run the website locally using your preferred development setup.

## Collaboration & workflow

We use GitHub to organize tasks, track progress and collaborate throughout the development process.

- Issues are used to break down the project into smaller tasks.
- Labels identify which project phase each task belongs to.
- Assignees help define responsibilities.
- Due dates help us keep track of deadlines.
- Pull requests are used to review and integrate code changes.

## Project goals

- Recreate the visual direction from the Figma design.
- Build a responsive website with a mobile-first approach.
- Implement interactive functionality using JavaScript.
- Follow accessibility best practices.
- Collaborate using Git and GitHub.
